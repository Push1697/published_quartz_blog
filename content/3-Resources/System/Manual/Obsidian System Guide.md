# 📘 Obsidian System Guide

Welcome to your centralized knowledge base. This vault connects the **PARA Method** (for organization) with **Zettelkasten** (for thinking and writing).

## 🏗️ The Structure

### 1. PROJECTS (`1-Projects`)

* **What**: Goals with a deadline (e.g., "Complete GCP Certification").
* **Action**: Create a folder for each project. Use the **New Project** template.
* **When done**: Move folder to `4-Archives`.

### 2. AREAS (`2-Areas`)

* **What**: Ongoing responsibilities (e.g., "Finance", "Health", "Journaling").
* **Action**: Store long-term tracking notes here.

### 3. RESOURCES (`3-Resources`)

* **What**: Things you want to keep for reference.
* **Zettelkasten**: Your "Second Brain" lives here.
  * `Literature Notes`: Summaries of books/articles/videos.
  * `Permanent Notes`: Your own atomic ideas, linked together.
  * `Reference`: Raw data, tables, cheatsheets.

### 4. ARCHIVES (`4-Archives`)

* **What**: Completed projects or inactive resources.

---

## 🔄 The Workflows

### 📥 1. Capture Everything

* Don't worry about where things go initially.
* Drop every idea, rapid note, or image into **`00-Inbox`**.
* *Tip: Use the "Untitled" notes for quick capture.*

### 🧠 2. Processing Knowledge (The Zettelkasten Loop)

1. **Consume**: Read a book or watch a video.
2. **Literature Note**: Create a note in `Literature Notes` using the **Zettel - Literature Note** template. Summarize the content.
3. **Distill (Permanent Note)**:
    * Review your Literature Note.
    * Extract *single concepts*.
    * Create a NEW note in `Permanent Notes` using the **Zettel - Permanent Note** template.
    * **Link it**: Connect this new note to existing notes (`[[Concept A]]`). This is how you "connect the dots".

### 🚀 3. Managing Projects

1. Create a folder in `1-Projects` named after your goal.
2. Create a note inside focused on the goal using the **New Project** template.
3. Break it down into **Milestones**.
4. Link any relevant **Zettelkasten** notes for research.

### 🔧 4. Troubleshooting Logs

* Encounter a bug? Don't just fix it and forget it.
* Create a note in `3-Resources` (or a specific tech folder) using the **Troubleshooting Log** template.
* Document the *Root Cause* and *Solution*. Next time, you'll search and find the answer instantly.

### 📅 5. The Weekly Review

* **When**: Every Friday/Sunday.
* **Action**: Create a note in `2-Areas/Journaling` using the **Weekly Review** template.
* **Steps**:
    1. Clean `00-Inbox` (Delete trash, file the rest).
    2. Check `1-Projects` (Are they moving?).
    3. Plan next week.

## 🎨 Tips for "Beautification"

* **Emojis**: Use emojis in folder names (e.g., `🚀 Projects`) to make them scanable.
* **Callouts**: Use `> [!INFO]` or `> [!TIP]` for colored boxes.
* **Linking**: The power is in `[[Links]]`. If you mention a concept, link it!
