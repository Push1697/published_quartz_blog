Installing nvim is crucial for any one new user. this is the most important for you to love your terminal without touching the mouse, you learn to operate the things.

this is the extended version of vim with more customization and advance features.

Let's start with installation of nvim in ubuntu.

#### Ubuntu
```
sudo apt get install neovim
```

#### How to launch nvim
just open terminal and type:

> nvim
